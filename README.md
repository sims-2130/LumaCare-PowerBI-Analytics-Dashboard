# LumaCare Power BI Data Analysis & Visualization
An enterprise-grade business intelligence and ETL architecture built for health services operational tracking. This project demonstrates core data engineering, transformation pipeline workflows, and key metric tracking.

---

### 🧠 Core Engineering & ETL Processes
This dashboard utilizes advanced **Power Query** processing steps to curate high-integrity operational tracking models:
* **Duplicate Elimination:** Applied systematic cleansing layers to remove duplicate transaction arrays and isolate uniquely indexed rows.
* **Category Standardization:** Standardized disparate Branch and Service operational records into unified relational dimensions.
* **Missing Value Imputation:** Engineered robust fallback logic to handle unassigned records and maintain metric precision across satisfaction tracking fields.

---

### 🛠️ Technical Specifications
* **Platform:** Power BI Desktop Architecture / Power Query Engine
* **Analytical Models:** Star Schema Relational Data Models
* **Transformations:** Advanced Conditional Column Merges & Data Cleaning Pipelines
